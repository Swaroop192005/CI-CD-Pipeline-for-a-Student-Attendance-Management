The gate sits at stage 6, before the image is built. If a browser journey fails, no image is published and nothing deploys. A check that runs after deployment can only report what users already have. The gate tests a throwaway container started from the very artefact that ships if it passes.

What each tool is for

DockerPackages the app with its runtime, and provides the lab: eight containers standing in for machines.
JenkinsDecides when a change ships. Eleven stages, defined in a Jenkinsfile versioned with the code.
SeleniumDrives a real browser through real tasks, so the gate tests the page a human sees.
AnsibleDeclares the state a host should be in and converges it. Agentless, over SSH.
PuppetThe same job, masterless, in its own declarative language. Both are demonstrated.
MavenOne command compiles, tests and packages, so the pipeline needs no bespoke build steps.

What the tests caught

  • The roster rendered blank. A template read a property that no longer existed, so the page silently hid its own Stop and Strike buttons. It passed every unit test.
  • A promise the code did not keep. The page said an override was logged against your name; only the role was recorded.
  • An escalated case vanished from the dashboard count.

None would fail a compile. None would be obvious in a demonstration.

One artefact is promoted, never rebuilt: the image tagged 1.0.19-6be7e00 — build number plus commit — is the one that reaches staging and production alike. Never only :latest, because a tag that moves cannot be rolled back to.

What this project does not solve

No database migrationsSchema managed by ddl-auto with no Flyway. A NOT NULL column cannot be added to a populated table — in production, data loss.
Observability stops at a health checkUp or down. Nothing reports slow, or failing for a fraction of users.
Single nodeNo load balancing, no blue-green, and a window during deployment where the service is down.
